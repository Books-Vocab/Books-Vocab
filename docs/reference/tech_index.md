| `graph_event_log.py` | `graph_events` + `graph_snapshots` | per-user 圖譜 append-only 變更帳本(**SoT 回溯**)。`GraphEventStore` 記 7 種 mutation(`link_added`/`updated`/`hidden`/`unhidden`/`deprecated`/`restored`(deprecated→active,與 unhidden 區隔)/`deleted`)每筆含 confidence/status before+after、`reason`(add/update 帶 link 當前理由)、`source`(`auto`=pipeline / `manual`=使用者 API / `ops`=ops_edit·運維遷移 / `synth`=合成回填)、`is_synthetic`;`event_id` 冪等、`ingested_at` 單調 watermark。共用 `sqlite_ledger.py`(serialized-tx recipe + 單調時鐘)。`GraphSnapshotStore` 存 links 全量快照(`links_json` + `is_synthetic`),`latest()` 以 `(taken_at desc, snapshot_id desc)` 決定式 tie-break;並已提供週期性 checkpoint policy:某 notebook 若尚無 snapshot，第一個真實 mutation 後立刻補一張；之後每累積固定數量 graph events 再補下一張，讓 replay 重建長度有界。攔截點在 `GraphStore`(唯一 100% 覆蓋,pipeline AI 回寫亦經此),emit 走單筆交易批寫，成功寫 event 後再依 provider 解析 live snapshot store 補 checkpoint(LRU 逐出後重建,不丟事件) |

| `secret_store.py` | secrets | 加密憑證 |
| `mem_log.py` | (in-memory) | admin in-memory log capture |

Data dir 透過 `KG_DATA_DIR` env 切換。`orphan_scan` 為 cross-DB consistency scanner(`/api/admin/orphan-scan`)。

**全域 store `lexical_cache.db`(`backend/src/kg/lexical.py:LexicalCache`,OUTSIDE `users/<uid>/`)**:字典 provider 的跨用戶快取與觀測面。3 表 —— `lexical_cache`(entry payload 快取,`is_negative` 分正負,正向 TTL `DICTIONARY_CACHE_TTL_DAYS`、負向 `DICTIONARY_NEGATIVE_CACHE_TTL_HOURS`)/ `lexical_provider_request`(每小時上游預算的原子預約帳,`reserve_provider_request` 走 `BEGIN IMMEDIATE`,跨 worker 共享;上限 `DEFAULT_PROVIDER_HOURLY_LIMIT=950`,對 FreeDictionary 的 1000/hr/IP 留安全邊際)/ `lexical_lookup_event`(**lookup outcome + 毫秒延遲 ledger**,唯一的 hit/miss/stale/429/error/latency 來源;outcome 詞彙 `LOOKUP_OUTCOMES` 九種,三種 429 分開記——`throttled`=我方 per-user 限流(使用者實際看到的 429)、`rate_limited`=上游回 429、`budget_exhausted`=我方每小時預算擋下;`negative_cached` 與 `negative` 分開,前者零上游成本;寫入 best-effort,sqlite 錯誤只記 log 不拋,保留 14 天於寫入時就地剪枝)。讀取入口一律 `ops_cli.py dictionary-health`。

**字典 sidecar(在 per-user `cards.db`,`backend/src/kg/cards/dictionary_models.py`)**:`dictionary_entry`(每張字典卡一列:provider / entry key / schema version / 選定 sense+example key / 離線 payload JSON / 授權四欄 / `materialization_status` `staged`→`active`)、`lexical_operations`(materialize saga ledger,`idempotency_key` 主鍵 + `request_hash`,status `started`→`judged`→`card_staged`→`graph_written`→`touched`→`completed`,`response_json` 供 replay)、`dictionary_promotion_jobs`(轉單字卡的 durable work item,`status`/`attempt_count`/`error_code`/`retryable`/`worker_id` fencing)、`dictionary_lifecycle_state`(archive/delete 的 card↔graph saga:`pending_action` + graph 快照,crash 後同狀態重試可續完原計畫)、`dictionary_archive_link_cause`(封存端點使 link 維持 deprecated 的持久理由,雙端 refcount)。`card` 表另加 `card_role` / `review_eligible` / `reader_hidden` / `promotion_state` / `promoted_at`(見 `card_format.md`)。盤點入口一律 `ops_cli.py dictionary-cards`。

**全域 store `shared_decks.db`（`backend/src/kg/shared_decks/store.py`，OUTSIDE `users/<uid>/`）**：共享牌組庫（Explore）中央 store，SQLModel scaffold，**owner 是 column 非 path**（鏡射 `translate_log` 跨用戶前例）。6 表：`shared_deck`（metadata/index plane，三軸刪除狀態 `visibility`×`status`×`is_deleted`，`UNIQUE(owner_id, source_notebook_id)`）/ `shared_deck_version`（immutable payload，`content_hash`）/ `shared_deck_card`（**content plane ONLY，零 SRS 欄位**——結構性去洩漏，`content_guid=uuid5(content+pos+mode+meaning)` 防同形字碰撞）/ `shared_deck_rating`（authority，one-vote-per-user）/ `shared_deck_report`（reason enum，per-reporter dedup）/ `shared_deck_copy_log`（idempotency，`(copier_id, idempotency_key)`）——`shared_deck_rating`/`shared_deck_report` 仍 Phase 3 forward-compat（未實作）；`shared_deck_copy_log` 已由 **Phase 2 copy** 寫入。`SharedDeckStore` 方法：`get` / `browse`（keyset）/ `page_cards`（keyset）/ `all_cards(deck_id,*,version)`（copy 全量讀）/ `publish_official`（官方注入，冪等 upsert 回 `{action,deckId,version,contentHash,cardCount}`）/ `record_copy` + `get_copy_log(copier_id,idempotency_key)`（copy 冪等 ledger）/ `increment_download_count`（atomic）；模組函式 `card_content_guid` / `canonical_card` / `deck_content_hash`。經 `deps._shared_deck_store` + `service_factories.create_shared_deck_store` LRU 注入。**在既有 per-user backup/erasure scope 外**（root-level DB，官方注入走 `build_official.py` 的 `backup_world` hook）。**Phase 2 copy** 起 stamp 的 provenance / barrier 欄位：`Card.source_shared_card_guid`（`cards/model.py`+`cards/schema.py`；由 `CardMutationMixin.add_shared_copy` 寫入，fresh SRS + strictly-monotonic `updated_at`）、`Notebook.source_shared_deck_id`/`source_version`（`notebook.py`，`NotebookResponse.sourceSharedDeckId`/`sourceVersion` camelCase）、`Notebook.is_staged`（**copy materialize barrier，與 `is_deleted` 正交**——staged 本在 materialize 前對每個 visibility query / world-export / projection / full-sync-list 全隱藏；`NotebookStore.all(include_deleted,include_staged)` 拆正交軸、`materialize` reveal-once、`hard_delete` + `CardMutationMixin.hard_delete_by_notebook` 為 rollback 補償）。

## Environment Variables

完整清單見 `docs/sop/deploy.md`。此處列分組與代表項:

- **LLM & Embedding**: `GEMINI_API_KEY` / `GEMINI_MODEL` / `EMBEDDING_MODEL` / `EMBEDDING_DIM` / `LLM_PROVIDER_*`(per-call-type 路由) / `LLM_PROVIDER_DEFAULT` / `JUDGE_CONFIDENCE_THRESHOLD`(judge link 接受門檻,default `0.7`;換低校準 judge model 時調低)

- **Secret encryption**: `SECRET_ENC_KEY`(可選)— `secret_store.py` 對 `enc:` stored secret 的對稱加密根金鑰,`sha256(SECRET_ENC_KEY)` 派生 Fernet key。**未設時 fallback `sha256(JWT_SECRET)`**(既有部署零破壞)。設了它後,**輪換 `JWT_SECRET` 不再令 stored secret 無法解密**(兩者脫鉤);解密採多金鑰容錯(當前 key 先試,失敗退回 legacy `sha256(JWT_SECRET)`),過渡期無需 re-encrypt migration。

- **Cache**: `TRANSLATE_CACHE_TTL_DAYS`
- **Dictionary (V1 rollout)**(`settings.py`): `DICTIONARY_LOOKUP_ENABLED`(default `false` — **rollout kill switch**,只關新搜尋 / 新 entry 讀取 / 新 materialization;既有字典卡的 detail / projection / selection / archive / delete / reader-visibility / promotion 一律不受影響,見 `routers/dictionary.py`)/ `DICTIONARY_PROVIDER_DEFAULT`(default `free_dictionary`;非此值一律 403,Cambridge adapter 是保留 seam 但無持久化授權)/ `DICTIONARY_CACHE_TTL_DAYS`(`30`,正向快取)/ `DICTIONARY_NEGATIVE_CACHE_TTL_HOURS`(`24`,負向快取)。字典查詢**不經 LLM、不耗 quota**;唯一耗 quota 的是 materialize 的 `manual_link` judge 與 promote 的 enrich(見 `cost_baseline.md`)

`ops/lib/streaming_command.py` 是長時 child process 的 machine-output-safe runner，亦提供 shell control plane capture CLI：library runner 不寫 parent stdout；capture CLI 只把 captured child stdout 原樣轉送，所有 progress 固定寫 stderr。progress 立即輸出 `start` / `spawned`、最長每 20 秒 `heartbeat`，每筆都含 phase、elapsed、PID、alive；child 正常 exit 時另寫 `done` + rc，且不回顯可能帶秘密的 raw argv。stdout/stderr 以獨立 reader 持續 drain，只保留 bounded tail，保留 child rc、signal 與分離 stderr 語意。child 另開 isolated session；parent 中斷或 deadline timeout 會對整個 process group TERM，逾期 KILL，timeout 固定回 rc 124；即使直接 child 已先退出，只要孫程序仍持 inherited pipe 也會清掉整個 group。`worktree_orchestrate.py` 的所有 shell gate，以及潛在長時 mutation / network probe（fetch、worktree add/remove、rebase、merge、push、ls-remote、branch teardown、committed sweep）都必須走此 runner；只有本機、預期快速的 parsed-output probe 可走 silent capture。`app_review_evidence.py` 的 desired shape/build/bundle、journey、physical demo、gate evaluation亦使用同一原語；`ios_ops.sh workflow release` 的 project settings、Organizer、TestFlight、ASC versions、App Review gate 五個來源也由 `ios_ops_stream_capture` 接線，stdout 保持單一 workflow JSON。測試：`ops/tests/test_streaming_command.py`、`ops/tests/test_worktree_orchestrate.py`、`ops/tests/test_app_review_evidence.py`、`ops/tests/test_ios_ops_release_heartbeat.sh`。
