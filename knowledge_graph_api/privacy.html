Privacy Policy

隱私政策

最後更新：2026 年 2 月

BooksBrowser 尊重並保護使用者的隱私。本政策說明我們如何收集、使用與保護您的資訊。

我們收集的資訊

類型 內容 目的
帳戶資訊 電子郵件、顯示名稱（由 Google / Apple 提供） 識別使用者、同步詞彙庫
詞彙資料 單字、翻譯、上下文句子 儲存於裝置；可選同步至伺服器
使用紀錄 API 請求計數、錯誤日誌 改善服務品質，不追蹤個人行為

資料安全

  • ✓ 所有伺服器通信使用 HTTPS（TLS 加密）
  • ✓ API 驗證使用 JWT Token
  • ✓ 本地資料由 iOS 系統保護
  • ✓ 無廣告、無行為追蹤、不與第三方共享資料

資料保留

  • 本地資料永久保留在您的裝置，直到您刪除應用程式
  • 伺服器同步資料可隨時要求刪除
  • 帳戶刪除後，主要伺服器資料會立即移除

第三方服務

  • Google 登入 — 由 Google 管理其隱私
  • Apple Sign-In — 由 Apple 管理其隱私
  • Gemini API — 用於詞彙 AI 增強功能（不存取完整詞彙庫）

您的權利

  • 存取您的個人資訊
  • 要求修正不準確的資訊
  • 要求刪除帳戶及所有相關資料
  • 查詢我們如何使用您的資訊

聯絡我們

如有任何隱私相關問題，請寄信至 max970228@gmail.com，或前往 支援頁面。
