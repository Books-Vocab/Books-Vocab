Privacy Policy

隱私政策

最後更新：2026 年 6 月

Books & Vocab 尊重並保護使用者的隱私。本政策說明我們如何收集、使用與保護您的資訊。

我們收集的資訊

類型 內容 目的
帳戶資訊 電子郵件、顯示名稱（由 Google / Apple 提供） 識別使用者、同步詞彙庫
詞彙資料 單字、翻譯、上下文句子 儲存於裝置；可選同步至伺服器
選取文本 您在書中選取的單字與其上下文句子／段落（每次最多約 1000 字元） 即時傳送至 AI 服務商（Google Gemini、DeepSeek）進行翻譯與詞彙增強；資料之留存與使用依各服務商隱私政策（見下方連結）
使用紀錄 API 請求計數、錯誤日誌、當機診斷（Sentry） 改善服務品質與穩定性，不追蹤個人行為、不用於廣告

資料安全

  • ✓ 所有伺服器通信使用 HTTPS（TLS 加密）
  • ✓ API 驗證使用 JWT Token
  • ✓ 本地資料由 iOS 系統保護
  • ✓ 無廣告、無行為追蹤、不為廣告或行銷目的共享資料
  • ✓ 僅為提供 AI 翻譯／詞彙功能，將您選取的文本傳送至下列 AI 服務商處理

資料保留

  • 本地資料永久保留在您的裝置，直到您刪除應用程式
  • 伺服器同步資料可隨時要求刪除
  • 帳戶刪除後，主要伺服器資料會立即移除

第三方服務

  • Google 登入 — 由 Google 管理其隱私
  • Apple Sign-In — 由 Apple 管理其隱私
  • Google Gemini API — 翻譯與詞彙增強。您選取的文本（單字及其上下文句子／段落）會傳送以產生結果；不存取完整詞彙庫
  • DeepSeek API — 翻譯與詞彙增強的另一 AI 供應商，傳送內容同上
  • Sentry — 當機與錯誤診斷，協助我們修復問題；不含您的詞彙內容

您的權利

  • 存取您的個人資訊
  • 要求修正不準確的資訊
  • 要求刪除帳戶及所有相關資料
  • 查詢我們如何使用您的資訊
