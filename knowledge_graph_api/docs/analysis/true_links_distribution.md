# 真實圖譜連結分析 (True Positive Link Distribution)

基於目前已存在的 38 條活躍連結（Active Links），我們對這 38 組單字的向量（Embedding）重新計算了它們彼此的「餘弦相似度 (Cosine Similarity)」。

這份數據揭示了在 Gemini Embedding 模型下，**真正有意義的關聯詞**在數學上的距離分佈。

## 📊 核心統計數據

*   **總活躍連結數**：38 條
*   **平均相似度 (Mean)**：`0.7493`
*   **最低相似度 (Min)**：`0.6636` (代表即使是最牽強的真實連結，相似度也有 0.66 以上)
*   **最高相似度 (Max)**：`0.9011`

### 📈 四分位數分佈 (Percentiles)

這代表了真實連結分佈的密集程度：
*   **第 25 百分位數 (25th percentile)**：`0.7027` (這代表有 75% 的真實連結，相似度都超過 0.70)
*   **中位數 (50th percentile)**：`0.7467`
*   **第 75 百分位數 (75th percentile)**：`0.7698`
