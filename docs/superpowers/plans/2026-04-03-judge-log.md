# Judge Log Implementation Plan (v2 — batch mode)

> **執行方式:** 使用 execute skill，所有 agent 皆 opus。

**Goal:** 記錄所有 judge 決策（含被拒絕的），補齊分析盲區。
**Architecture:** 新增 `judge_log.py` SQLite module → 修改 `_parse_batch_response` 收集 raw decisions → `_call_batch` 觸發 logging → caller 傳入 context。
**Tech Stack:** SQLite WAL mode、threading.Lock、side-channel output parameter

## 現狀（382a2cb 後）

judge.py 已重構為 batch mode：
- `_parse_batch_response(content, candidates)` — module-level，回傳 `dict[str, Judgement | None]`
- `Judge._call_batch(target_word, target_meaning, candidates)` — 單次 LLM call
- `Judge.evaluate_batch(target_word, target_meaning, candidates)` — 分 chunk 呼叫 `_call_batch`
- `Judge.evaluate()` — thin wrapper，用 `evaluate_batch` + `"_single"` key
- `ManualLinkJudge.evaluate()` — 獨立，單 pair，always accepted

pipeline_service `_step_link()`:
- 按 `from_id` 分組 candidates
- 每組呼叫 `judge.evaluate_batch(card_a.content, card_a.meaning, batch_candidates)`
- `batch_candidates` 格式：`list[tuple[str, str, str]]` = `(to_card_id, word, meaning)`
- ThreadPoolExecutor 8 workers 並行

#### 2a. `_parse_batch_response` 新增 `raw_decisions` 輸出參數

現有簽名（judge.py:46）：
```python
def _parse_batch_response(
    content: str | None,
    candidates: list[tuple[str, str, str]],

```

改為：
```python
def _parse_batch_response(
    content: str | None,
    candidates: list[tuple[str, str, str]],
    raw_decisions: list[dict] | None = None,
) -> dict[str, Judgement | None]:
```

在每個決策點，if `raw_decisions is not None`，append 一筆 dict：

| 決策點 | verdict | confidence | accepted | reject_reason |
|--------|---------|------------|----------|---------------|
| Parse fail（line 61）| `"parse_error"` | 0.0 | 0 | `"parse_error"` |
| No match in response（line 104）| `"no_response"` | 0.0 | 0 | `"no_response"` |
| Extract fields fail（line 112）| `"parse_error"` | 0.0 | 0 | `"parse_error"` |
| `not_applicable`（line 115）| raw `link_val` | raw `confidence` | 0 | `"not_applicable"` |
| `confidence < 0.7`（line 115）| raw `link_val` | raw `confidence` | 0 | `"low_confidence"` |
| Invalid LinkKind（line 122）| raw `link_val` | raw `confidence` | 0 | `"invalid_kind"` |
| Accepted（line 125）| raw `link_val` | raw `confidence` | 1 | `None` |
| Beyond response length（line 128）| `"no_response"` | 0.0 | 0 | `"no_response"` |

每筆 dict 格式：
```python
{"to_id": cid, "verdict": ..., "confidence": ..., "accepted": ..., "reject_reason": ..., "reason": ...}
```

**回傳值不變**，`raw_decisions` 是 side-channel output。

    self,
    target_word: str,
    target_meaning: str,

    similarities: dict[str, float] | None = None,

`_call_batch` 同樣新增 `from_id` 和 `similarities`。

在 `_call_batch` 內，呼叫 `_parse_batch_response` 時傳入 `raw_decisions=[]`，然後：
```python
results = _parse_batch_response(content, candidates, raw_decisions=raw_decisions)
if self.user_id and raw_decisions:
    from . import judge_log
    for d in raw_decisions:
        judge_log.record(
            user_id=self.user_id,
            notebook_id=self.notebook_id,
            from_id=from_id,
            to_id=d["to_id"],
            similarity=(similarities or {}).get(d["to_id"]),
            verdict=d["verdict"],
            confidence=d["confidence"],
            accepted=bool(d["accepted"]),
            reject_reason=d.get("reject_reason"),
            reason=d.get("reason", ""),
            source="auto",
        )
return results
```

#### 2d. `Judge.evaluate` (thin wrapper) 轉發參數

```python
def evaluate(
    self,
    word_a: str,
    meaning_a: str,
    word_b: str,
    meaning_b: str,
    *,
    from_id: str = "",
    to_id: str = "",
    similarity: float | None = None,
) -> Judgement | None:
    sims = {to_id: similarity} if similarity is not None and to_id else None
    cands = [(to_id or "_single", word_b, meaning_b)]
    results = self.evaluate_batch(
        word_a, meaning_a, cands,
        from_id=from_id,
        similarities=sims,
    )
    return results.get(to_id or "_single")
```
